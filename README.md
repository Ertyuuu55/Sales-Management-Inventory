# Sales-Management-Inventory
Sales Management Inventory Web and Database

# Using Code Tutorial
1. Download supermarket-app and supermarket_fix.sql.
2. Open up xampp start Apache and MySQL.
3. Enter MySQL, create new database, name supermarket_fix and import the file.
4. Save supermarket-app on the htdocs (inside xampp folder).
5. Enter link: http://localhost/supermarket-app/public/login.php to access the web
